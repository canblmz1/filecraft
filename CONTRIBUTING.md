# Contributing

Use the commands in the [README](README.md) to build and test. Submit focused changes that describe how to reproduce and validate them. Keep fixture files synthetic and small. Run formatting, tests, Clippy and the frontend build before proposing a change.

For a new processing operation, document input and output formats, licensing, preservation constraints, resource bounds, cancellation and verification evidence. Prefer tests that cover measurable regressions such as metadata retention, wrong output type or publication of a result that misses a stated goal.
