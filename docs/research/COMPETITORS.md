# Competitor research

Snapshot prepared 2026-11-24. See [sources and release trails](SOURCES.md) and the [feature matrix](FEATURE_MATRIX.md). Format families are representative. Installation and resource notes describe documented runtimes or dependencies. Comparative throughput, latency, peak RAM, CPU use and energy were not benchmarked. UX observations come from upstream documentation, screenshots and source layouts. The local FFmpeg 8.1 build encoded a generated test clip with libx264. The other desktop products were assessed through upstream material.

## Universal processing

- **Filee.** MIT desktop/CLI for Windows, macOS and Linux with platform-specific engine availability. Broad support including JPEG/PNG/HEIC, PDF/Office, HWP, MP4, audio, e-books and archives. The radial drop palette, shell integration, preset gallery, parallel queue and watch folders streamline repeat usage. Local conversion, optional downloads with checksums, automatic update checks that can be disabled. Source documentation describes disk/CRC/archive guards, target-size video bitrate budgeting and retry, multistep routing, and separable engine downloads. The documented Whisper engine package is Windows x64 only. No cross-format allocation of a shared output budget with a per-file verification report was identified in the reviewed engine documentation.
- **CloudConvert.** Proprietary hosted UI/API, no client install. More than 200 formats across media, documents, archives and other categories. Job DAGs, bulk integration, import/export and OAuth make automation a strength. Service-side compute and file transport are inherent to hosted processing. Conversion job status and vendor security documentation are available.
- **Convertio.** Proprietary hosted web/API for media, documents, archives, fonts and e-books. Browser upload, target selection and API wrappers streamline single and multiple inputs. Jobs expose status and output retrieval. API requires credentials and uses processing quotas. Files are handled by the service as described in its security terms.
- **FileFlows.** Local server/web console for Windows, macOS, Linux and Docker. Watches libraries and composes conditional flows for video, audio, images, archives, comics and e-books. Node orchestration, logs, scripting and plugins are strengths. Setup includes a server and processing environment. Check the current edition and plugin licenses per deployment. Configurable nodes and scripts make workflow trust a deployment concern.
- **File Converter.** GPL-3.0 Windows Explorer extension. Installer, context menu and presets for batches of media, images and documents. Local FFmpeg, ImageMagick and Ghostscript underpin feature coverage. The shell integration is Windows-specific.
- **XnConvert.** Proprietary local batch image GUI on Windows, macOS and Linux. Reads common images, RAW, JPEG XL, AVIF and HEIC with support varying by direction. Ordered edits, resize, crop and metadata operations, reusable action presets and folder monitoring. Company use requires a purchased license. Product scope is image-oriented.
- **Format Factory.** Windows freeware baseline for media and document conversion. The official publisher site timed out during review. Supported paths, licensing terms, current release, bundled components, security, verification and automation require independent verification before relying on this comparison.
- **7-Zip.** Local archive GUI on Windows and CLI builds across platforms. Supports 7z, ZIP, TAR and multiple extraction formats. Batch commands, archive test and AES-256 in supported formats. Small standalone installer, with compression costs dependent on method and dictionary. LGPL/BSD with unRAR restrictions on portions. Archive integrity checks cover the archive rather than source document fidelity.

## PDF

- **Stirling PDF.** Open-core desktop, web and self-hosted PDF platform. PDF/images/Office workflows, OCR, editing, security and a private API. Local and self-hosted options, with Docker/JVM and optional engine footprint tied to deployment. Release history includes active PDF editing development. Product scope is PDF-centric.
- **Adobe Acrobat.** Proprietary desktop on Windows/macOS plus mobile/web editions. PDF editing, comparison, OCR, redaction, signatures and Office conversion. Acrobat Pro supports guided batch actions. Desktop processing and hosted services have different data paths and entitlements. Paid plans and cloud workflows make edition and feature-specific review necessary.
- **PDFgear.** Proprietary freeware with desktop and mobile variants plus separate web tools. PDF editing, signing, OCR and conversion to/from office and image formats. Desktop installer and approachable task launcher. Hosted AI/e-sign functionality is a distinct data path. Vendor documentation provides feature claims, not independently measured fidelity.
- **PDF24 Creator.** Proprietary freeware for Windows. Installer with PDF printer, toolbox, OCR, compression, conversion, page tools and batch utility flows. Vendor documents offline desktop processing. Strong coverage even for commercial use without a paid license, desktop bound to Windows.
- **BentoPDF.** AGPL-3.0/commercial variants. Browser-side PDF editing, conversion and compression with WASM components. Zero-install web UX, self-host and air-gap instructions. Default components can fetch WASM from CDN. Air-gapped deployment requires local asset configuration. The browser is the processing runtime.
- **PDF Arranger.** GPL-3.0 Python/GTK with pikepdf for Windows and Linux distributions. Thumbnail-driven multi-document merge, split, crop, rotate and reorder. Local save, system package/installer paths and structural editing. Scope is page arrangement, so OCR and target-size optimization sit outside its documented feature set.
- **Smallpdf.** Proprietary web and desktop. PDF/Office/image conversion, compression, merge and protection. Desktop supports documented offline PDF workflows, and availability depends on app/plan. Hosted tools have a separate upload path. UX makes individual tasks easy to discover.
- **iLovePDF.** Proprietary web, Windows/macOS desktop and mobile. Local desktop processing, PDF/Office/JPEG conversions and organization. Web suite includes OCR, repair and comparison. Automation is separately available through an API. Confirm each feature and limit by edition.

## Video and audio

- **HandBrake.** GPL-2.0 desktop and CLI for Windows/macOS/Linux. Outputs MP4, MKV and WebM with configurable video/audio/subtitles. Presets, queue, previews, average-bitrate or constant-quality controls and optional hardware encoding. Local encodes can be CPU-intensive, depending on encoder. Constant-quality output size varies with source.
- **FFmpeg.** LGPL with GPL or nonredistributable configuration variants. Windows/macOS/Linux CLI builds and libraries with extensive audiovisual formats, stream copy, filters, PSNR, SSIM and optional VMAF. FFprobe, null decode and progress output enable verification and automation. Binary size, codec support and CPU/RAM vary by build and operation. Protocol and demuxer settings matter for local-only adapters.
- **Shutter Encoder.** GPL project, local desktop builds for Windows/macOS/Linux. Multimedia functions include codecs, transcodes, trimming, audio extraction and file-size settings. Function-first GUI and batch processing expose FFmpeg breadth. Installed engine/runtime and hardware settings affect resource use. Review output criteria function by function.
- **LosslessCut.** GPL-2.0 Electron desktop for Windows/macOS/Linux. FFmpeg-based trimming, merge and remux of common media containers, with project/segment import-export and batch workflows. Stream copy minimizes re-encode work. Precise frame cuts can depend on keyframes or the experimental smart-cut path.
- **Audacity.** GPL-3.0 desktop on Windows/macOS/Linux. WAV, AIFF, MP3, FLAC, Ogg and additional optional FFmpeg formats. Waveform editor, effects, loudness, macros and batch export. Local projects and audio editing are central. Optional sharing is a separate path. Scope is audio.
- **MediaInfo.** BSD-2-Clause GUI/CLI/library. Reads common video/audio and some image/text formats on multiple desktop platforms. Codec, rate, tracks, dimensions, duration and structured reports; suitable for post-job probing. Reports container/stream properties, so a separate full decode is needed for decoded-content validation.

## Image and document processing

- **ImageMagick.** Apache-style ImageMagick license, desktop-platform CLI/API. Broad raster/vector document formats vary with delegates and policy. Batch conversion, image comparisons, explicit resource/security policies and metadata operations. Powerful but requires deployment policy and delegate review.
- **libvips.** LGPL-2.1-or-later library/CLI with sequential and demand-driven processing. Supports JPEG, PNG, TIFF, WebP and formats through optional codecs. Upstream publishes benchmark methodology. Strong memory-oriented design; actual comparisons depend on operation and input. No bundled desktop batch workbench.
- **Squoosh.** Apache-2.0 client-side web app with WASM codecs for JPEG/PNG/WebP/AVIF and others. Interactive visual preview and size comparison. Browser processing, codec assets and browser memory affect offline setup and large files. UI emphasizes per-image tuning.
- **ImageOptim.** GPL macOS frontend to image optimizers, supports PNG, JPEG and GIF. Drag batch and command-line invocation. Strips metadata according to settings. Optimizer engines and settings affect CPU usage. App modifies files in place, so preserving originals needs workflow care.
- **Caesium.** GPL-3.0 cross-platform desktop with compression, resize, preview and batch controls for common images including JPEG, PNG and WebP. Local operation. Feature fit is image-centric and size/preview controls deserve direct comparison once FileCraft broadens image support.
- **LibreOffice.** MPL-2.0 desktop suite for Windows/macOS/Linux with ODF, Office and PDF export, plus headless commands. Formatter and document model make it a strong document engine. Full suite, fonts, filters and user profile influence footprint/fidelity. Test macros, links and layout with isolated profiles before integration.
- **Pandoc.** GPL-2.0-or-later CLI on major desktops. Markdown/HTML/DOCX/ODT/EPUB and more, with PDF requiring a suitable PDF engine. Batch scripts, explicit readers/writers and filters. Its intermediate model can omit format-specific layout features on conversion, as the manual notes.
- **Tesseract.** Apache-2.0 OCR library/CLI. Raster images in, text, hOCR, TSV or searchable PDF out. Local language data and model choice determine footprint and recognition behavior. File lists and structured outputs aid automation. No built-in general PDF rearrangement.
- **OCRmyPDF.** MPL-2.0 Python CLI for searchable PDF/PDF-A workflows. Adds text layers to scans, with language packs and optional image conditioning. Dependencies include Tesseract and PDF processing tools and vary by version. Setup is heavier than a single binary. Its security model calls for isolation for untrusted input.
